Alie uses **your** provider key, so its model usage is billed by your provider. Beaver lets you put limits on it.

```bash
beaver alie spend-cap                              # the workspace's daily and per-session limits, and today's spend
beaver alie spend-cap set --daily 20 --session 5   # USD per day and per conversation (both required)
beaver alie usage <session>                        # token usage for one session
```

<Note>
A new, lower limit applies once saved. A conversation already over it is not affected retroactively; the limit takes effect at its next usage check.
</Note>

AI usage is also measured against your plan — see [Plans and billing](/teams/plans-and-billing).
