Last time, `beaver connect` learned to inspect a machine and only offer the roles it actually qualifies for. That inspection was mostly self-reported, though — Docker installed, systemd available, disk and memory free. Two of the checks behind it deserved to be more than a best guess, so we tightened them up.

## A real reachability check, not a reminder

Hosting an application only works if the internet can actually reach it. Until now, `connect` handled that with a static line telling you to go verify your own ports were open — useful advice, but not a check.

It's a check now. When you run `connect`, Beaver confirms whether the ports a hosted application would need are actually reachable from the internet, and only warns about the ones that aren't:

```txt
✓ Public reachability (port 80, 443)
```

```txt
⚠ Public reachability: port 443 not reachable from the internet
```

If a port comes back closed, that's real, actionable information — open it, or plan to put a reverse proxy or tunnel in front of it — rather than a caveat you'd see no matter what.

## Telling laptops from desktops

The other check that got sharper: what kind of machine is this, anyway? `connect` uses that to decide whether to recommend Host duty, or to nudge you to double check first.

The old heuristic leaned on whatever hardware happened to be present — a battery, a Wi-Fi card. That's a reasonable signal on an actual laptop, but it also meant a desktop tower with a Wi-Fi adapter (common enough) could get misread as portable. `connect` now looks at the machine's actual form factor first, falling back to the old signals only when that isn't available. The capability check now shows its work, too — the machine type it detected, not just the verdict:

```txt
⚠ Portable device (laptop) detected
  Chassis: Notebook
  Battery: present
  Wi-Fi: present
```

## Same roles, better evidence

None of this changes what qualifies a machine for Builder, Host, or both — it just makes the checks behind that decision something you can actually see and trust, instead of taking on faith.
