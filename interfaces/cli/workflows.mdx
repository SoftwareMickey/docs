The CLI can do nearly everything, and it is the only way to enrol a machine. Running `beaver` on its own deploys the project in the current folder; `beaver --help` lists the groups. This page maps the common jobs to the pages that explain them.

## Set up

| Workflow | Command | How-to |
| --- | --- | --- |
| Install and sign in | [`beaver login`](/cli/login) | [Install the CLI](/install/cli) |
| Check this computer | [`beaver doctor`](/cli/doctor) | [Doctor](/install/doctor) |
| Connect a machine | [`beaver connect`](/cli/connect) | [Connect a machine](/infrastructure/connect-a-machine) |
| Create a Beaver Cloud | [`beaver cloud create`](/cli/cloud) | [Clouds](/infrastructure/clouds) |
