Beaver is one product with three ways in: the **Dashboard** (the web app), **Beaver Desktop** and the **Beaver CLI**. They act on the same workspace, so
you can start in one and continue in another. This section is the map: where each thing is in each interface, and which interface can do which task.

<Tip>
**Start here:** the [capability matrix](/interfaces/capability-matrix) answers "can I do X in Y?" for every task, with the exact path or command.
</Tip>
