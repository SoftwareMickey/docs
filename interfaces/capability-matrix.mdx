Find a task, then read across. **✓ Yes** means you can do the whole task there; **◐ Partly** means you can do part of it or the interface shows you the command to run;
**— No** means that interface cannot do it, and the cell says where to go instead; **○ Not yet** means it is planned and not available.

<Info>
Desktop is mostly a place to look. Where an action would change something it opens a sheet with the exact `beaver` command to run — those cells read **Partly**.
The [overview](/interfaces/overview) explains why.
</Info>

## Reading the guides

Every cell links to the page that explains the task. The interface guides — [Dashboard](/interfaces/dashboard/tour) and [Desktop](/interfaces/desktop/shell-tour) — say where each screen is;
the how-to pages say how to do the task itself. State that follows you between interfaces is covered in [How state is shared](/interfaces/how-state-is-shared).
