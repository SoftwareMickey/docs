This page is a map, not a manual: each workflow names the screen to open and links the page that explains the task.

## As a developer

| Workflow | Where | How-to |
| --- | --- | --- |
| Deploy a repository | **Deploy application** on the home screen | [Deploy from a repository](/deploy/from-github) |
| Add environment variables | Deployment → **Environments** | [Environment variables](/deploy/environment-variables) |
| Attach a custom domain | Deployment → **Domains** | [Domains](/network/domains) |
| Read what happened to a request | Deployment → **Logs** | [Logs](/operate/logs) |
| Promote or roll back a release | Deployment → **Overview**, **Deployments** | [Promote](/deploy/promote), [Rollback and recovery](/deploy/rollback-and-recovery) |
| Publish a project as a template | **Activity → Publish template** | [Publishing a template](/deploy/publishing-a-template) |

## As an operator

| Workflow | Where | How-to |
| --- | --- | --- |
| Check fleet health | **Dashboard** home, **Nodes** | [Machines and roles](/infrastructure/machines-and-roles) |
| Triage an incident | **Incidents**, **Notifications** | [Incidents](/operate/incidents) |
| Drain a machine before maintenance | **Clouds → Drain** | [Drain and evacuate](/infrastructure/drain-and-evacuate) |
| Block an address or turn on lockdown | Deployment → **Firewall** | [Firewall](/network/firewall) |
| Scale a deployment | Deployment → **Load Balancing** | [Scale](/deploy/scale) |
| Put an existing app behind Beaver Edge | **Beaver Edge → Connect an app** | [Beaver Edge](/network/beaver-edge) |

## As a team lead

| Workflow | Where | How-to |
| --- | --- | --- |
| Invite someone | **Team → Members → Invite member** | [Invite members](/teams/invite-members) |
| Protect production | **Team → Access policies** | [Production approvals](/teams/production-approvals) |
| Decide an approval | **Team → Approvals** | [Production approvals](/teams/production-approvals) |
| Review who did what | **Team → Activity** | [Audit history](/teams/audit-history) |
| Change plan or seats | **Billing → Plan & seats** | [Plans and billing](/teams/plans-and-billing) |
| Turn on 2-step verification | **Settings → Personal → Security** | [Two-step verification](/teams/two-step-verification) |
