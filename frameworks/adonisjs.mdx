# AdonisJS

AdonisJS is a full-featured MVC framework for Node.js, with batteries-included tooling for ORM, validation, and auth. It requires a build step (`node ace build`) before running the production image.

<CardGroup cols={2}>
  <Card title="Ace Build Step" icon="hammer">
    Compile with `node ace build` before running the production image.
  </Card>
  <Card title="Automatic Port Binding" icon="settings">
    Set `PORT` from the environment and match it in your Dockerfile's `EXPOSE`.
  </Card>
</CardGroup>

---

## Dockerfile

<CodeGroup>
```dockerfile Dockerfile
FROM node:20-slim AS build
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN node ace build

FROM node:20-slim
WORKDIR /app
COPY --from=build /app/build ./
RUN npm install --production
EXPOSE 3333
CMD ["node", "bin/server.js"]
```
</CodeGroup>

## Environment Variables

<CodeGroup>

import env from '#start/env'
