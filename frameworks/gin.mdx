# Gin

Gin is a high-performance HTTP web framework for Go, popular for APIs and microservices. Package it with a standard multi-stage Go Dockerfile.

<CardGroup cols={2}>
  <Card title="Multi-Stage Build" icon="docker">
    Compile in a full Go image, ship only the binary in a minimal final image.
  </Card>
  <Card title="Automatic Port Binding" icon="settings">
    Set `PORT` from the environment and match it in your Dockerfile's `EXPOSE`.
  </Card>
</CardGroup>

---

## Dockerfile

<CodeGroup>
```dockerfile Dockerfile
FROM golang:1.22 AS build
WORKDIR /app
COPY . .
RUN go build -o server .

FROM debian:bookworm-slim
COPY --from=build /app/server /server
EXPOSE 8080
CMD ["/server"]
```
</CodeGroup>

<CodeGroup>
```go main.go
package main

import "github.com/gin-gonic/gin"

func main() {
  r := gin.Default()

  r.GET("/", func(c *gin.Context) {
    c.JSON(200, gin.H{
      "message": "Hello from Gin on VectorIHub",
    })
  })

  r.Run(":8080")
}
```
</CodeGroup>
