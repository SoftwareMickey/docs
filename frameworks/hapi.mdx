# Hapi

Hapi is a configuration-driven Node.js framework built for building robust applications and APIs. Package it in a standard Node.js Dockerfile and deploy it as a live server.

<CardGroup cols={2}>
  <Card title="No Build Step Needed" icon="rocket">
    Plain Hapi apps run directly — no compilation required.
  </Card>
  <Card title="Automatic Port Binding" icon="settings">
    Set `PORT` from the environment and match it in your Dockerfile's `EXPOSE`.
  </Card>
</CardGroup>

---

## Dockerfile

<CodeGroup>
```dockerfile Dockerfile
FROM node:20-slim
WORKDIR /app
COPY package*.json ./
RUN npm install --production
COPY . .
EXPOSE 3000
CMD ["node", "server.js"]
```
</CodeGroup>

<CodeGroup>
```js server.js
const Hapi = require('@hapi/hapi');

const init = async () => {
  const server = Hapi.server({ port: process.env.PORT || 3000, host: '0.0.0.0' });

  server.route({
    method: 'GET',
    path: '/',
    handler: () => 'Hello from Hapi on VectorIHub',
  });

  await server.start();
};

init();
```
</CodeGroup>
