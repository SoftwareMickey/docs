# Chi

Chi is a lightweight, idiomatic router for building Go HTTP services, built entirely on the standard library's `net/http`. Package it with a standard multi-stage Go Dockerfile.

<CardGroup cols={2}>
  <Card title="Multi-Stage Build" icon="docker">
    Compile in a full Go image, ship only the binary in a minimal final image.
  </Card>
  <Card title="Automatic Port Binding" icon="settings">
    Set `PORT` from the environment and match it in your Dockerfile's `EXPOSE`.
  </Card>
</CardGroup>

---

## Dockerfile

<CodeGroup>
```dockerfile Dockerfile
FROM golang:1.22 AS build
WORKDIR /app
COPY . .
RUN go build -o server .

FROM debian:bookworm-slim
COPY --from=build /app/server /server
EXPOSE 8080
CMD ["/server"]
```
</CodeGroup>

<CodeGroup>
```go main.go
package main

import (
  "net/http"
  "github.com/go-chi/chi/v5"
)

func main() {
  r := chi.NewRouter()

  r.Get("/", func(w http.ResponseWriter, r *http.Request) {
    w.Write([]byte("Hello from Chi on VectorIHub"))
  })

  http.ListenAndServe(":8080", r)
}
```
</CodeGroup>
