# Fiber

Fiber is an Express-inspired Go web framework built on top of Fasthttp. Package it with a standard multi-stage Go Dockerfile.

<CardGroup cols={2}>
  <Card title="Multi-Stage Build" icon="docker">
    Compile in a full Go image, ship only the binary in a minimal final image.
  </Card>
  <Card title="Automatic Port Binding" icon="settings">
    Set `PORT` from the environment and match it in your Dockerfile's `EXPOSE`.
  </Card>
</CardGroup>

---

## Dockerfile

<CodeGroup>
```dockerfile Dockerfile
FROM golang:1.22 AS build
WORKDIR /app
COPY . .
RUN go build -o server .

FROM debian:bookworm-slim
COPY --from=build /app/server /server
EXPOSE 8080
CMD ["/server"]
```
</CodeGroup>

<CodeGroup>
```go main.go
package main

import "github.com/gofiber/fiber/v2"

func main() {
  app := fiber.New()

  app.Get("/", func(c *fiber.Ctx) error {
    return c.SendString("Hello from Fiber on VectorIHub")
  })

  app.Listen(":8080")
}
```
</CodeGroup>
