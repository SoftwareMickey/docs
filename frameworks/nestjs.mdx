# NestJS

NestJS is a structured, TypeScript-first Node.js framework for building scalable backend services. It requires a build step to compile TypeScript before it can run.

<CardGroup cols={2}>
  <Card title="TypeScript Build Step" icon="hammer">
    Compile with `nest build` before running the production image.
  </Card>
  <Card title="Automatic Port Binding" icon="settings">
    Set `PORT` from the environment and match it in your Dockerfile's `EXPOSE`.
  </Card>
</CardGroup>

---

## Dockerfile

<CodeGroup>
```dockerfile Dockerfile
FROM node:20-slim AS build
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build

FROM node:20-slim
WORKDIR /app
COPY --from=build /app/dist ./dist
COPY --from=build /app/node_modules ./node_modules
EXPOSE 3000
CMD ["node", "dist/main.js"]
```
</CodeGroup>

<CodeGroup>
```ts main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  await app.listen(process.env.PORT ?? 3000);
}
bootstrap();
```
</CodeGroup>
