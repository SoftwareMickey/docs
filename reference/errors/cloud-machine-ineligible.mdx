**Machine cannot join this cloud**

One or more requirements for joining a cloud are not met. Each requirement is listed with its status and repair.

| | |
| --- | --- |
| Code | `CLOUD_MACHINE_INELIGIBLE` |
| Kind | Eligibility |
| HTTP status | `409` |
| CLI exit status | `1` |

## What to do

Every requirement is listed with its status. Fix the failed ones — each has its own repair — then run the command again, or use `--check` to see the verdict without changing anything.

## What the response contains

Every failure — in the table output, `--json`, `--yaml` and the API — carries the same fields: `code`, `message`, `changed` (whether anything was altered), `conditions` (each requirement checked, with `status`, `detail` and a `repair`), `repairs`, a `retry` command and a `request_id`. Branch on `error.code`, never on the message text.

```json
{
  "ok": false,
  "error": {
    "code": "CLOUD_MACHINE_INELIGIBLE",
    "message": "Machine cannot join this cloud",
    "operation": "cloud.machine.add",
    "changed": false,
    "conditions": [
      {
        "id": "machine.online",
        "label": "Machine agent is online",
        "status": "passed"
      },
      {
        "id": "cloud.wireguard_unavailable.srv_1",
        "label": "WireGuard tooling is missing",

  }
}
```
