**Don't include your email address in your password.**

The new password contains the account's email address or its mailbox name.

| | |
| --- | --- |
| Code | `PASSWORD_CONTAINS_ACCOUNT_INFO` |
| Kind | Invalid input |
| HTTP status | `400` |
| CLI exit status | `1` |

## What to do

The response names the flag or argument and shows an accepted value. Run `beaver help <command>` for the command's flags.

## What the response contains

Every failure — in the table output, `--json`, `--yaml` and the API — carries the same fields: `code`, `message`, `changed` (whether anything was altered), `conditions` (each requirement checked, with `status`, `detail` and a `repair`), `repairs`, a `retry` command and a `request_id`. Branch on `error.code`, never on the message text.

```json
{
  "ok": false,
  "error": {
    "code": "PASSWORD_CONTAINS_ACCOUNT_INFO",
    "message": "Don't include your email address in your password.",
    "changed": false,
    "conditions": [],
    "repairs": [],
    "request_id": "req_…",
    "error": "Don't include your email address in your password."
  }
}
```

Look it up offline with `beaver help PASSWORD_CONTAINS_ACCOUNT_INFO`. See [Exit codes and output formats](/reference/exit-codes-and-output) for what a script can rely on.
