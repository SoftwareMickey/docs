**This account has no password yet.**

The account signs in with GitHub or Google only. Add a password from Settings, Security instead of changing one.

| | |
| --- | --- |
| Code | `PASSWORD_NOT_SET` |
| Kind | Resource State |
| HTTP status | `409` |
| CLI exit status | `1` |

## What to do

Read the conditions in the response: each says what was checked and how to fix it.

## What the response contains

Every failure — in the table output, `--json`, `--yaml` and the API — carries the same fields: `code`, `message`, `changed` (whether anything was altered), `conditions` (each requirement checked, with `status`, `detail` and a `repair`), `repairs`, a `retry` command and a `request_id`. Branch on `error.code`, never on the message text.

```json
{
  "ok": false,
  "error": {
    "code": "PASSWORD_NOT_SET",
    "message": "This account has no password yet.",
    "changed": false,
    "conditions": [],
    "repairs": [],
    "request_id": "req_…",
    "error": "This account has no password yet."
  }
}
```

Look it up offline with `beaver help PASSWORD_NOT_SET`. See [Exit codes and output formats](/reference/exit-codes-and-output) for what a script can rely on.
