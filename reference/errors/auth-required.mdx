**You are not signed in**

No session was presented. Sign in, then retry.

| | |
| --- | --- |
| Code | `AUTH_REQUIRED` |
| Kind | Sign-in |
| HTTP status | `401` |
| CLI exit status | `1` |

## What to do

Sign in again with `beaver login`. In CI, set `BEAVER_TOKEN` and run `beaver login` once.

## What the response contains

Every failure — in the table output, `--json`, `--yaml` and the API — carries the same fields: `code`, `message`, `changed` (whether anything was altered), `conditions` (each requirement checked, with `status`, `detail` and a `repair`), `repairs`, a `retry` command and a `request_id`. Branch on `error.code`, never on the message text.

```json
{
  "ok": false,
  "error": {
    "code": "AUTH_REQUIRED",
    "message": "You are not signed in",
    "changed": false,
    "conditions": [],
    "repairs": [],
    "request_id": "req_…",
    "error": "You are not signed in"
  }
}
```

Look it up offline with `beaver help AUTH_REQUIRED`. See [Exit codes and output formats](/reference/exit-codes-and-output) for what a script can rely on.
