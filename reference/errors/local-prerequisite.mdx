**Something this machine needs is missing**

A local prerequisite (writable directory, git repository, reachable Docker, parseable config file) is not met. Raised before any request is sent.

| | |
| --- | --- |
| Code | `LOCAL_PREREQUISITE` |
| Kind | Invalid input |
| HTTP status | `400` |
| CLI exit status | `1` |

## What to do

The response names the flag or argument and shows an accepted value. Run `beaver help <command>` for the command's flags.

## What the response contains

Every failure — in the table output, `--json`, `--yaml` and the API — carries the same fields: `code`, `message`, `changed` (whether anything was altered), `conditions` (each requirement checked, with `status`, `detail` and a `repair`), `repairs`, a `retry` command and a `request_id`. Branch on `error.code`, never on the message text.

```json
{
  "ok": false,
  "error": {
    "code": "LOCAL_PREREQUISITE",
    "message": "Something this machine needs is missing",
    "changed": false,
    "conditions": [],
    "repairs": [],
    "request_id": "req_…",
    "error": "Something this machine needs is missing"
  }
}
```

Look it up offline with `beaver help LOCAL_PREREQUISITE`. See [Exit codes and output formats](/reference/exit-codes-and-output) for what a script can rely on.
