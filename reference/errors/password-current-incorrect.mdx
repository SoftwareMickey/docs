**Your current password is incorrect.**

Changing a password needs the current one, and the one given does not match.

| | |
| --- | --- |
| Code | `PASSWORD_CURRENT_INCORRECT` |
| Kind | Sign-in |
| HTTP status | `401` |
| CLI exit status | `1` |

## What to do

Sign in again with `beaver login`. In CI, set `BEAVER_TOKEN` and run `beaver login` once.

## What the response contains

Every failure — in the table output, `--json`, `--yaml` and the API — carries the same fields: `code`, `message`, `changed` (whether anything was altered), `conditions` (each requirement checked, with `status`, `detail` and a `repair`), `repairs`, a `retry` command and a `request_id`. Branch on `error.code`, never on the message text.

```json
{
  "ok": false,
  "error": {
    "code": "PASSWORD_CURRENT_INCORRECT",
    "message": "Your current password is incorrect.",
    "changed": false,
    "conditions": [],
    "repairs": [],
    "request_id": "req_…",
    "error": "Your current password is incorrect."
  }
}
```

Look it up offline with `beaver help PASSWORD_CURRENT_INCORRECT`. See [Exit codes and output formats](/reference/exit-codes-and-output) for what a script can rely on.
