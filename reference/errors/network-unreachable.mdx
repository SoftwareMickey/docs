**The Beaver server could not be reached**

The connection to the server failed before any response arrived (refused, reset, unreachable network).

| | |
| --- | --- |
| Code | `NETWORK_UNREACHABLE` |
| Kind | Temporary |
| HTTP status | `503` |
| CLI exit status | `1` |

## What to do

Read the conditions in the response: each says what was checked and how to fix it.

## What the response contains

Every failure — in the table output, `--json`, `--yaml` and the API — carries the same fields: `code`, `message`, `changed` (whether anything was altered), `conditions` (each requirement checked, with `status`, `detail` and a `repair`), `repairs`, a `retry` command and a `request_id`. Branch on `error.code`, never on the message text.

```json
{
  "ok": false,
  "error": {
    "code": "NETWORK_UNREACHABLE",
    "message": "The Beaver server could not be reached",
    "changed": false,
    "conditions": [],
    "repairs": [],
    "request_id": "req_…",
    "error": "The Beaver server could not be reached"
  }
}
```

Look it up offline with `beaver help NETWORK_UNREACHABLE`. See [Exit codes and output formats](/reference/exit-codes-and-output) for what a script can rely on.
