**An account with this email may already exist.**

The account could not be created, most often because the email address is already registered. Sign in, or reset the password.

| | |
| --- | --- |
| Code | `SIGNUP_FAILED` |
| Kind | Conflict |
| HTTP status | `409` |
| CLI exit status | `1` |

## What to do

The response names the resource it conflicts with. Resolve that, or choose a different name, then run the command again.

## What the response contains

Every failure — in the table output, `--json`, `--yaml` and the API — carries the same fields: `code`, `message`, `changed` (whether anything was altered), `conditions` (each requirement checked, with `status`, `detail` and a `repair`), `repairs`, a `retry` command and a `request_id`. Branch on `error.code`, never on the message text.

```json
{
  "ok": false,
  "error": {
    "code": "SIGNUP_FAILED",
    "message": "An account with this email may already exist.",
    "changed": false,
    "conditions": [],
    "repairs": [],
    "request_id": "req_…",
    "error": "An account with this email may already exist."
  }
}
```

Look it up offline with `beaver help SIGNUP_FAILED`. See [Exit codes and output formats](/reference/exit-codes-and-output) for what a script can rely on.
