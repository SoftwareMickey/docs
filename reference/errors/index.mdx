Every refusal from the CLI, the API and the Dashboard carries a stable **code**. Scripts branch on `error.code` in `--json` output; people read the conditions and repairs under it. `beaver help CODE` prints the same entry offline. For the status a command exits with, see [Exit codes and output formats](/reference/exit-codes-and-output).
