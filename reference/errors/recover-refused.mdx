**The service cannot be recovered right now**

A precondition for recreating the container is not met. The response carries a refusal_code and the next action.

| | |
| --- | --- |
| Code | `RECOVER_REFUSED` |
| Kind | Resource State |
| HTTP status | `409` |
| CLI exit status | `10` |

## What to do

The response carries a `refusal_code` and the next command. See [A service's container went missing](/operate/service-container-missing#recover-was-refused).

## What the response contains

Every failure — in the table output, `--json`, `--yaml` and the API — carries the same fields: `code`, `message`, `changed` (whether anything was altered), `conditions` (each requirement checked, with `status`, `detail` and a `repair`), `repairs`, a `retry` command and a `request_id`. Branch on `error.code`, never on the message text.

```json
{
  "ok": false,
  "error": {
    "code": "RECOVER_REFUSED",
    "message": "The service cannot be recovered right now",
    "changed": false,
    "conditions": [],
    "repairs": [],
    "request_id": "req_…",
    "error": "The service cannot be recovered right now"
  }
}
```

Look it up offline with `beaver help RECOVER_REFUSED`. See [Exit codes and output formats](/reference/exit-codes-and-output) for what a script can rely on.
