Terms are spelled the way the product spells them. Where two surfaces use different words for one thing (the Dashboard's **node** is Desktop's and the CLI's **machine**), both are listed.

### 2-step verification

Second sign-in factor.

**Where you see it:** Dashboard Security.

Read more: [2-step verification](/teams/two-step-verification)

### activity

Feed of published items and workspace events.

**Where you see it:** Dashboard + Desktop.

Read more: [Activity, following, and Explore](/operate/activity-and-following)

### Alie

Beaver's infrastructure AI assistant.

**Where you see it:** Dashboard + Desktop.

Read more: [What is Alie?](/alie/what-is-alie)

### approval

A human confirmation required before a protected action.

**Where you see it:** Dashboard Team + Desktop Approvals.

Read more: [Production safety and approvals](/teams/production-approvals)

### Beaver

The product family (CLI + Desktop + Dashboard + Cloud + Edge + Services).

**Where you see it:** every interface and the binary.

### Beaver CLI

The `beaver` command-line tool.

**Where you see it:** Desktop Settings > Beaver CLI & Agent; install pages.

Read more: [Beaver CLI reference](/cli)

### Beaver Cloud

A group of your machines managed together.

**Where you see it:** Dashboard Clouds; Desktop navigator.

Read more: [Beaver Cloud](/infrastructure/beaver-cloud)

### Beaver Desktop

The desktop application.

**Where you see it:** desktop app.

Read more: [Beaver Desktop shell tour](/interfaces/desktop/shell-tour)

### Beaver Edge

Edge routing/performance product.

**Where you see it:** Dashboard Edge.

Read more: [Edge and performance controls](/network/beaver-edge)

### build minutes

The plan allowance for building images.

**Where you see it:** Dashboard sidebar.

### Builder

A machine role that builds your images.

**Where you see it:** machine role chosen in beaver connect; Dashboard add-node.

Read more: [Machine Roles](/infrastructure/machines-and-roles)

### compose application

An application defined by a Docker Compose file.

**Where you see it:** Dashboard Composers detail; CLI compose.

Read more: [Deploy a Docker Compose app](/deploy/compose-applications)

### Composer

Dashboard's name for compose stacks.

**Where you see it:** Dashboard sidebar.

Read more: [Deploy a Docker Compose app](/deploy/compose-applications)

### container

A running instance of an image.

**Where you see it:** Dashboard + CLI.

Read more: [Containers and replicas](/deploy/containers-and-replicas)

### Dashboard

The web application at the product domain.

**Where you see it:** Dashboard sidebar.

Read more: [Dashboard tour and navigation](/interfaces/dashboard/tour)

### deployment

One running (or past) release of a project.

**Where you see it:** Dashboard Deployments.

Read more: [Deployments](/deploy/deployment-lifecycle)

### device authorization

Signing a CLI or Desktop in via the browser.

**Where you see it:** Dashboard /oauth/approve; CLI login; Desktop sign-in.

Read more: [beaver login](/cli/login)

### drift

Difference between desired and actual state.

**Where you see it:** Desktop Configuration; CLI state.

Read more: [State and drift](/operate/state-and-drift)

### environment

A named target such as staging or production.

**Where you see it:** Dashboard Project environments.

Read more: [Environments](/deploy/environments)

### firewall

Rules and posture controlling inbound traffic.

**Where you see it:** Dashboard deployment tab.

Read more: [Firewall](/network/firewall)

### gateway

A Beaver Cloud member machine that also accepts public inbound traffic for the cloud.

**Where you see it:** Beaver Cloud.

Read more: [Beaver Cloud](/infrastructure/beaver-cloud)

### Host

A machine role that runs your containers.

**Where you see it:** machine role chosen in beaver connect.

Read more: [Machine Roles](/infrastructure/machines-and-roles)

### incident

A detected operational problem.

**Where you see it:** Dashboard Incidents.

Read more: [Incidents](/operate/incidents)

### machine

A computer enrolled in Beaver that can run workloads.

**Where you see it:** Desktop navigator; docs.

Read more: [Machine Roles](/infrastructure/machines-and-roles)

### node

Dashboard's name for a machine.

**Where you see it:** Dashboard sidebar.

Read more: [Machine Roles](/infrastructure/machines-and-roles)

### passkey

A WebAuthn credential for sign-in.

**Where you see it:** Dashboard Security.

Read more: [2-step verification](/teams/two-step-verification)

### plan

Subscription tier and its limits.

**Where you see it:** Dashboard Billing.

Read more: [Plans and billing](/teams/plans-and-billing)

### project

The thing you deploy: a repo or folder plus its configuration.

**Where you see it:** Dashboard Projects.

Read more: [Projects](/deploy/projects)

### reconcile

Bring actual state back to desired.

**Where you see it:** CLI.

Read more: [Check for drift and reconcile](/operate/drift-and-reconcile)

### replica

One of several running copies of a container.

**Where you see it:** Dashboard Containers.

Read more: [Containers and replicas](/deploy/containers-and-replicas)

### repository access

Permission for Beaver to read your repositories.

**Where you see it:** Desktop Settings; Dashboard Integrations.

Read more: [Signing in vs. connecting repositories](/teams/signing-in-and-repository-access)

### resource usage

CPU memory and bandwidth consumption view.

**Where you see it:** Dashboard sidebar.

### role

A member's permission level in a workspace.

**Where you see it:** Dashboard Members.

Read more: [Roles and permissions](/teams/roles-and-permissions)

### service

A managed database or broker Beaver runs for you.

**Where you see it:** Dashboard Services; Desktop Services.

Read more: [Services catalog](/data/services)

### sign-in method

Email Google or GitHub used to sign in.

**Where you see it:** Dashboard Settings.

Read more: [Sign-in methods](/teams/sign-in-methods)

### team workspace

A workspace shared by several members.

**Where you see it:** Dashboard Team.

Read more: [Create a team](/teams/create-a-team)

### template

A published project others can deploy.

**Where you see it:** Dashboard Activity.

Read more: [Publishing a template](/deploy/publishing-a-template)

### VectorIHub

The platform and company behind Beaver.

**Where you see it:** site and company name; Dashboard footer/marketing.

### workspace

The scope that owns projects clouds and services; personal or team.

**Where you see it:** Dashboard + Desktop switcher.

Read more: [Accounts, workspaces and teams](/teams/accounts-workspaces-teams)
