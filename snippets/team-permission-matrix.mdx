#### Policy switches

| Switch | Default | Who can change it | What it does |
|---|---|---|---|
| `developer_production` | off | Owner or Admin | Let Developers deploy to protected (production) environments directly, without an approval. |
| `developer_machines` | off | Owner or Admin | Let Developers enroll and manage machines. |
| `developer_secrets` | off | Owner or Admin | Let Developers reveal secret values in protected environments without an approval. In other environments they can already read values, and writing a value never needs this. |
| `allow_link_invites` | off | Owner only | Allow invitation links that any verified account holding the link can accept, instead of one tied to an email address. |
| `protected_environments` | the environment named production | Owner or Admin | Which environments count as production for the protections above. |
| `require_approval_for` | nothing | Owner or Admin | Sensitive actions that need a second person's approval even from someone who could do them directly. It only applies while the workspace has another person who can approve. |
