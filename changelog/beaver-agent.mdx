Every server enrolled with `beaver connect` now gets more than a registration — it gets a persistent Beaver Agent, installed and started automatically as part of connecting, with no extra steps required on your end.

Once running, the agent keeps a live connection back to your workspace and reports the machine's health, so Beaver knows in real time whether a server is actually online and ready — not just whether it checked in once, a while ago. This is what turns a connected server from an entry in your fleet list into a machine Beaver can actually reach to do work.

A few commands are available if you ever need to check on it directly:

| Command | Description |
| --- | --- |
| `agent status` | Check whether the Beaver Agent is running on this machine. |
| `agent logs` | Follow the agent's live activity log. |
| `agent start` / `agent stop` | Start or stop the agent manually. |
| `agent install` | Reinstall the agent if it's ever missing. |

The agent updates itself in lockstep with the CLI, so a single `beaver update` keeps both current together.
