Introduced Bring Your Own Cloud (BYOC): deploy onto infrastructure you already own, instead of a VectorIHub-managed environment. This marks our repositioning from a cloud hosting platform to a deployment layer that works across infrastructure providers.

The new model is deliberately thin:

```
Developer → VectorIHub → Infrastructure Provider
```

This turns infrastructure providers into replaceable execution targets. Developers keep control of their own cloud resources, and VectorIHub focuses on making deployment consistent across whatever they choose.
