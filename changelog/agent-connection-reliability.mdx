Some connected servers could see the Beaver Agent repeatedly fail to connect, or drop its connection shortly after establishing one, depending on the network path between the server and Beaver.

This has been fixed — the agent now connects and stays connected reliably across these configurations, so a server that's online and healthy reliably shows as online and healthy, with no manual restart needed to recover.
