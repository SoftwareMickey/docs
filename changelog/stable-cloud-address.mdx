## What changed

- A Beaver Cloud can have a **stable public IP and hostname** of its own. See [Public IP and private name of a cloud](/network/cloud-ingress).
- Domains on a cloud use **one record** that points at that address, plus a TXT record that proves you own the domain. You no longer create one record per gateway.
- A domain is checked in three separate steps (ownership, routing, TLS), and `beaver domain show` prints each one with the exact records to create.
- Domains behind **Cloudflare's proxy** are supported: keep the proxy on for the route record.
- A stale or extra address in your DNS no longer makes a domain fail.

## What stays the same

Domains that already work keep working. If yours still uses the old per-gateway records, `beaver domain repoint <domain-id>` prints the new ones; create them and Beaver moves the domain over by itself with no interruption.

## New commands

`beaver cloud ingress` (show, status, enable, disable, probe, guard) and `beaver domain show`.
