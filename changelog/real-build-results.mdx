When Beaver builds your project, it no longer just tells you whether the build passed or failed — it tells you exactly what was produced.

Every successful build now returns the pushed image's digest and size, along with the exact source commit it was built from and how long the build took. That's the foundation the next phase of Beaver builds on: knowing precisely what was built is what makes it possible to deploy that exact, verified artifact next, instead of re-resolving a mutable tag and hoping it's still the same thing.

Nothing changes about how you trigger a build — this is purely richer information coming back once it's done.
