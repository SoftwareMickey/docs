The readiness check introduced in Server Readiness Checks now looks deeper into two of its most important signals.

Docker verification now confirms a server can actually push an image, not just that Docker is installed and running — checking that its Docker Hub login is present and still accepted, the same way pushing an image would.

Repository access is more resilient too: if connecting over SSH doesn't work, Beaver automatically falls back to HTTPS before giving up, and can confirm a specific branch actually exists rather than just that the repository is reachable at all.
