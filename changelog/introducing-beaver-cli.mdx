Beaver CLI is the execution engine that runs inside your own infrastructure — bringing building, deploying, and operating applications directly to your servers, while VectorIHub coordinates everything from its control plane. Your source code and builds never leave your infrastructure.

This initial release focuses on authentication and project management:

| Command | Description |
| --- | --- |
| `login` | Authenticate your VectorIHub account and create a local session. |
| `logout` | Sign out and remove your local credentials. |
| `github` | Display the GitHub accounts connected to your VectorIHub workspace. |
| `help` | List available commands. |
| `exit` | Close the Beaver CLI session. |

Support for registering your own servers as deployment targets (`connect`) is coming next.
