## Examples

<Info>
  **Reviewed against source**: examples on this page were checked against `beaver-cli` source and its own `--help` output, not executed end-to-end against a live workspace.
</Info>

```bash
beaver shell
```

The default `beaver` command deploys the current project. Use `beaver shell` when you prefer a persistent interactive session with command history.
