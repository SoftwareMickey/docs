Part of the session family: [`login`](/cli/login) → **whoami** (this page) →
[`logout`](/cli/logout).

## Purpose

A cheap, offline "am I signed in, and as whom" check — it reads the local session file
directly rather than making a network call, so it works even without connectivity and never
fails just because your account or the API is unreachable.

## Syntax

```bash
beaver whoami [flags]
```

Takes no arguments.

## Flags

<ParamField query="--json" type="boolean" default="false">
  Print the result as JSON. See [shared flags](/cli/shared-flags#json) — no command-specific
  interaction here.
</ParamField>

<ParamField query="--output" type="string" default="table">
  Output format: `table`, `json`, or `yaml`. See [shared flags](/cli/shared-flags#output).
</ParamField>

## Consequences

Purely a read — no state changes on any run.

## Results & failures

| Situation | What you'll see | What to do |
| --- | --- | --- |
| Signed in | Account name, user ID, session expiry | Nothing — informational. |
| Not signed in | `You are not signed in.` (exit reflects `logged_in: false` in `--json`) | Run `beaver login`. |
| Session expired | `Expired · expired <duration> ago` in the Session line | Run `beaver login` again. |
