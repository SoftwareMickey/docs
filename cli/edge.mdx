---
title: "beaver edge"
description: "Manage Connected Apps for external services."
---

## Examples

```bash
beaver edge apps
beaver edge app add
beaver edge app show <connected-app-id>
beaver edge app verify <connected-app-id>
beaver edge backends <connected-app-id>
beaver edge logs <connected-app-id>
beaver edge traffic <connected-app-id>
beaver edge firewall --help
```

Connected Apps front an existing external service. Verify its domain and origin before making it public.
