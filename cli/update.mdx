---
title: "beaver update"
description: "Update Beaver CLI to the latest or a pinned release."
---

## Examples

<Info>
  **Reviewed against source**: examples on this page were checked against `beaver-cli` source and its own `--help` output, not executed end-to-end against a live workspace.
</Info>

```bash
beaver update
beaver update --version <version>
```

Restarts are required before the new binary is used. If the requested version is already installed, Beaver exits without changing it.
