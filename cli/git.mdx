## What this is — and is not

`beaver git --auth` checks the GitHub CLI login on **this machine**, for builds that run here.
It is local only: Beaver Cloud never sees it.

- It is **not** how Beaver reads your repositories — that is [`beaver github install`](/cli/github).
- It is **not** how you sign in to Beaver — that is [`beaver login`](/cli/login).

See [Signing in vs. connecting repositories](/teams/signing-in-and-repository-access).

## Examples

<Info>
  **Reviewed against source**: examples on this page were checked against `beaver-cli` source and its own `--help` output, not executed end-to-end against a live workspace.
</Info>

```bash
beaver git --auth
```

Run this before deployment when Beaver cannot access the required GitHub repository.
