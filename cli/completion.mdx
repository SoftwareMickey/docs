## Examples

<Info>
  **Reviewed against source**: examples on this page were checked against `beaver-cli` source and its own `--help` output, not executed end-to-end against a live workspace.
</Info>

```bash
beaver completion bash
beaver completion zsh
beaver completion fish
beaver completion powershell
```

The script is written to standard output; redirect it to the completion location for your shell.
