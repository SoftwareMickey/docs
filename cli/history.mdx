## Purpose

Use `beaver history` to recall what you ran recently, without a dashboard round trip. This is
a **local, personal** record kept on this machine — distinct from any workspace-wide audit
trail your team can see.

## Syntax

```bash
beaver history [flags]
```

## Flags

<ParamField query="--project" type="string" default="">
  Only show entries for this project.
</ParamField>
<ParamField query="--since" type="string" default="">
  Only show entries newer than this, e.g. `1h`, `24h`, `1d`.
</ParamField>

## Consequences

Purely a read — no state changes on any run. History is kept per machine; running commands
from a different machine (or a fresh install) starts a new, separate history.

## Results & failures

| Situation | What you'll see | What to do |
| --- | --- | --- |
| Success | A list of recently run commands | Nothing further. |
| Invalid `--since` | An error naming the invalid duration | Use a Go-style duration, e.g. `1h`, `24h`, `168h`. |

## Used in

- General troubleshooting — recalling exactly what was run before an issue appeared.
