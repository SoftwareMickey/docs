## Purpose

Use `beaver github` to see how you sign in to Beaver and which GitHub accounts (via the Beaver
GitHub App) Beaver can read repositories from — with each connection's health. Use
`beaver github install` to give Beaver access to repositories, so `beaver deploy --git` and
`beaver compose deploy` can see them, and `beaver github branches` to list a repository's
branches when scripting a deploy. For managing integrations generally (not just GitHub), see
[`beaver integrations`](/cli/integrations).

<Note>
  Signing in with GitHub only proves who you are; it never gives Beaver access to your
  repositories. Repository access is the explicit grant made by `beaver github install`. Both
  are separate from [`beaver git --auth`](/cli/git), which only checks the GitHub login on the
  machine you run it on.
</Note>

## Syntax

```bash
beaver github [subcommand] [flags]
```

| Subcommand | Purpose |
| --- | --- |
| *(none)* | Show your sign-in methods and each connected GitHub account, with its health (connected, suspended, disconnected). |
| `accounts` | Alias for the bare command. |
| `install` | Give Beaver access to your GitHub repositories, and wait for the result. |
| `branches` | List a repository's branches. |

## Flags

<ParamField query="--json" type="boolean" default="false">
  On the bare command: print the connection status as JSON, for scripts.
</ParamField>
<ParamField query="--no-browser" type="boolean" default="false">
  On `install`: print the URL instead of opening a browser (SSH, CI). The command still waits;
  open the URL on any device signed in to the same Beaver account.
</ParamField>
<ParamField query="--no-wait" type="boolean" default="false">
  On `install`: return right after opening the browser instead of waiting for the result.
</ParamField>
<ParamField query="--timeout" type="duration" default="10m">
  On `install`: how long to wait for the connection to finish.
</ParamField>
<ParamField query="--repo" type="string" default="" required>
  On `branches`: repository clone URL — the same value `beaver deploy --repo` accepts.
  Required.
</ParamField>

## Consequences

`install` opens the Beaver GitHub App's install page in your browser — connecting an account
is a GitHub-side authorization, not something that happens without your explicit approval
there. Beaver then asks GitHub to confirm your account has access to what you installed; if
GitHub can't confirm it, nothing is connected.

## Exit codes for `install`

Scripts can branch on the ending. The words are the same ones the web and desktop apps show.

| Exit code | Result | Meaning |
| --- | --- | --- |
| `0` | connected, or requested | Connected — or an organization owner has been asked to approve it. |
| `3` | cancelled | You backed out on GitHub. No access was granted. |
| `4` | denied | GitHub did not confirm you control that installation. Nothing was saved. |
| `5` | failed | GitHub returned an error while finishing. Nothing was saved. |
| `6` | expired | The connection attempt expired; run `beaver github install` again. |
| `7` | timeout | Gave up waiting. If you finished in the browser, run `beaver github` to check. |

## Examples

<Info>
  **Reviewed against source**: examples on this page were checked against `beaver-cli` source and its own `--help` output, not executed end-to-end against a live workspace.
</Info>

<CodeGroup>

```bash List connected accounts
beaver github
```

```bash Connect a new account
beaver github install
```

```bash Over SSH, without a browser
beaver github install --no-browser
```

```bash Machine-readable status
beaver github --json
```

```bash List a repo's branches (for scripted deploys)
beaver github branches --repo https://github.com/ada/paperclip
```

</CodeGroup>

## Results & failures

| Situation | What you'll see | What to do |
| --- | --- | --- |
| No accounts connected | A message that no GitHub repositories are connected | Run `beaver github install`. |
| A connection shows *suspended* | The GitHub App installation is suspended | Ask an owner of that GitHub account to unsuspend it. |
| A connection shows *disconnected* | The app was uninstalled or lost access | Run `beaver github install` to reconnect. |
| `install` ends *denied* | Exit code `4` | Make sure your browser is signed in to the right GitHub account, then retry. |
| `branches` with an inaccessible repo | An error naming the access issue | Confirm your connected account can see that repository. |

Every message is explained in [Troubleshooting GitHub](/guides/troubleshooting-github).
