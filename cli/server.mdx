## Examples

<Info>
  **Reviewed against source**: examples on this page were checked against `beaver-cli` source and its own `--help` output, not executed end-to-end against a live workspace.
</Info>

```bash
beaver server --list
beaver server update <machine-id> --name "Production API"
beaver server update <machine-id> --role host
beaver server update <machine-id> --labels env=production,region=us-east
beaver server rename <machine-id> <name>
beaver server remove [machine-id] [--yes]
```

`--role` sets the most the machine may ever do (Builder, Host, or both). If the machine is in a Beaver Cloud, that cloud's own setting still applies on top — a machine enrolled as a Host can be a
network member only there. See and change it with [`beaver cloud machine policy`](/cli/cloud#what-a-machine-may-do-member-vs-compute).

`--labels` replaces the complete label set. Removing a server disconnects it from Beaver; it does not delete the physical machine.
