# Go

Go is fully supported on VectorIHub — package your compiled binary with a `Dockerfile` and deploy it like any other language. Go's static binaries make for especially small, fast-starting images.

<CardGroup cols={2}>
  <Card title="Bring Your Own Dockerfile" icon="docker" href="/deploying/dockerfile-requirements">
    A standard multi-stage Go build — no VectorIHub-specific build config required.
  </Card>
  <Card title="Any Module Setup" icon="package">
    Works with any project using `go.mod`.
  </Card>
</CardGroup>

---

## Example Dockerfile

<CodeGroup>
```dockerfile Dockerfile
FROM golang:1.22 AS build
WORKDIR /app
COPY . .
RUN go build -o server .

FROM debian:bookworm-slim
COPY --from=build /app/server /server
EXPOSE 8080
CMD ["/server"]
```
</CodeGroup>

<Tip>A multi-stage build keeps your final image small — only the compiled binary ships, not the Go toolchain.</Tip>
