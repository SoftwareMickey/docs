# JavaScript and TypeScript

JavaScript and TypeScript are fully supported on VectorIHub — as with every language, all that's required is a `Dockerfile` that builds and runs your project. This covers everything from single-page frontends to full backend APIs.

<CardGroup cols={2}>
  <Card title="Bring Your Own Dockerfile" icon="docker" href="/deploying/dockerfile-requirements">
    Package your app with a standard Node.js-based Dockerfile — no VectorIHub-specific build config required.
  </Card>
  <Card title="Any Package Manager" icon="package">
    npm, yarn, pnpm, or bun — whichever your Dockerfile installs with.
  </Card>
</CardGroup>

---

## Example Dockerfile

<CodeGroup>
```dockerfile Dockerfile
FROM node:20-slim

WORKDIR /app
COPY package*.json ./
RUN npm install --production
COPY . .

EXPOSE 3000
CMD ["node", "server.js"]
```
</CodeGroup>

<Tip>TypeScript projects build the same way — just add your `tsc`/bundler build step before the final `CMD`.</Tip>
