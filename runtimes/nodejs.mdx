# Node.js Runtime

VectorIHub runs your Node.js application exactly as your `Dockerfile` defines it — this page covers the patterns that work well for Node.js images specifically.

<CardGroup cols={2}>
  <Card title="Any Base Image" icon="docker">

## Static Frontend vs. Live Server

Node.js covers two very different deployment shapes — make sure your Dockerfile matches the one your app needs:

<Tabs>
  <Tab title="Static Build (React, Vue, Angular, ...)">
    Build your app, then serve the static output with a lightweight web server — no Node process needs to keep running.

    <CodeGroup>
    ```dockerfile Dockerfile
    FROM node:20-slim AS build
    WORKDIR /app
    COPY package*.json ./
    RUN npm install
    COPY . .
    RUN npm run build

    FROM nginx:alpine
    COPY --from=build /app/dist /usr/share/nginx/html
    EXPOSE 80
    ```
    </CodeGroup>
  </Tab>
  <Tab title="Live Server (Express, Next.js SSR, ...)">
    Build your app, then run it as a live Node process.

    <CodeGroup>
    ```dockerfile Dockerfile
    FROM node:20-slim AS build
    WORKDIR /app
    COPY package*.json ./
    RUN npm install
    COPY . .
    RUN npm run build

    FROM node:20-slim
    WORKDIR /app
    COPY --from=build /app ./
    EXPOSE 3000
    CMD ["node", "server.js"]
    ```
    </CodeGroup>
  </Tab>
</Tabs>

<Tip>Match your deployment's port setting to whatever your Dockerfile `EXPOSE`s and your app listens on — see [Deployment Configuration](/deploying/deployment-configuration).</Tip>
