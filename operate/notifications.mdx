Beaver notifies you about things that need attention. Each notification has a **severity** — `info`, `success`, `warning`, `critical` or `security` — and you read them in one inbox across the interfaces.

## Read them

<Tabs>
  <Tab title="Dashboard">Open **Notifications** in the sidebar; notification and social preferences are on the Activity settings page.</Tab>
  <Tab title="Desktop">The notification inbox is built into the app; **Settings → Notifications** and on-call views hold your preferences.</Tab>
  <Tab title="CLI">
    ```bash
    beaver notifications                       # your notifications
    beaver notifications --unread
    beaver notifications --severity=critical   # info | success | warning | critical | security
    beaver notifications watch                 # stream new ones as they arrive
    ```
  </Tab>
</Tabs>

## Digests

A digest bundles non-urgent notifications into one message. In a team workspace an Owner or Admin sets the **default**; any member who chose their own digest setting — including "immediate" — keeps it.
**Critical and security notifications are never held for a digest.**

```bash
beaver workspace digest                                    # show the default
beaver workspace digest --schedule daily --hour 18 --timezone Africa/Nairobi
beaver workspace digest --schedule off
```

## On-call and escalation

```bash
beaver workspace on-call        # who is on call now, per schedule — the same resolution used to page people
beaver workspace escalation     # escalation policies for unacknowledged critical alerts
```

Both are read-only views. What `on-call` shows is who an alert would actually reach.
